# CS22 Course Website
[![Netlify Status](https://api.netlify.com/api/v1/badges/1d16af53-9645-43e4-9a58-087ca70dceb8/deploy-status)](https://app.netlify.com/sites/cs22/deploys)

This is the source code for Brown CS22's Course Website. 

## Access & Deploy
The course site is being deployed automatically (on every commit) by [Netlify](https://www.netlify.com/). No additional configuration is required at this end. 

All branches are also automatically deployed (which allows for access to previous offerings of the course) to `[branch].cs22.io`. For example, [`2021-summer.cs22.io`](https://2021-summer.cs22.io/). The main branch is published to `main.cs22.io`, `cs22.io`, `cs22.netlify.app`, and `cs22.cafe` (themed for this year's offering of the course). The `.io` and `.netlify.app` variants include automatic redirects to `cs22.cafe`. 

Temporarily, while the course site is being developed, `2022-spring-landing` is set as the production environment. We'll switch over once the semester starts. 

In the future, if need be, we can switch to staging/production branches. 

## Prior Course Sites
Previous course sites are branched as `YYYY-season`. At the end of every semester that the course is offered, branch `main` into a branch for said semester.
